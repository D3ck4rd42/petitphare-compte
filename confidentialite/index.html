Petit Phare

Politique de confidentialité

Apps Scoriki, Minuki et QuestTrail · mise à jour le 2 octobre 2026

En bref. Sans compte, tout reste sur le téléphone : rien ne part nulle part. Si un parent crée un compte famille, les données des apps sont sauvegardées sur un serveur situé en France, pour les retrouver sur un autre téléphone et les partager entre les appareils de la famille. Pas de publicité, pas de mesure d'audience, aucune donnée vendue ni partagée à des fins commerciales.

Qui est responsable

Les apps sont éditées sous le nom Petit Phare par Matthieu Colle, responsable du traitement des données. Pour toute question ou demande : contact@petitphare.fr.

Sans compte : rien ne quitte le téléphone

Les trois apps fonctionnent entièrement sans compte. Les missions, les points, les moments, les parcours et les réglages sont alors enregistrés sur le téléphone seulement. Désinstaller l'app les efface.

Avec un compte famille : ce qui part sur le serveur

Seul un parent crée un compte, avec son adresse e-mail. Les téléphones des enfants n'ont ni adresse ni mot de passe : le parent les relie par un code, et chacun reçoit un identifiant technique anonyme.

  • Le parent : son adresse e-mail, pour se connecter par un code reçu par e-mail.
  • Les enfants : le prénom ou le pseudo que le parent choisit, et un avatar éventuel. Aucune date de naissance.
  • Scoriki : les missions, les points gagnés, la boutique de récompenses et les récompenses données.
  • Minuki : les moments de la journée, les tâches qui les composent, les séances terminées, les choix de l'enfant (compagnon, pion, voix) et les bons livrés.
  • QuestTrail : la progression de chaque parcours, enregistrée au jour près, sans heure ; les prénoms de l'équipage ; les réglages ; les parcours achetés.
  • Les appareils reliés : l'app concernée, le nom générique de l'appareil (« Téléphone de l'enfant ») et l'enfant auquel chaque appareil est rattaché.

Ne partent jamais : la position du téléphone (QuestTrail se sert du GPS sur le téléphone seulement), les photos prises dans Minuki, les codes parent des apps, et les heures précises auxquelles un enfant joue un parcours.

Les adresses IP, que tout serveur voit passer :

  • pour se protéger des essais de code en série, le serveur note l'adresse IP de chaque essai de code d'appairage, effacée au bout d'un jour ;
  • le service de connexion garde, pour chaque session ouverte, l'adresse IP et le type de navigateur ou d'appareil, effacés avec la session, ainsi qu'un journal des connexions (adresse e-mail, adresse IP), effacé au bout de 30 jours ;
  • notre hébergeur, Supabase, garde des journaux techniques des appels au serveur, adresse IP comprise, pendant 7 jours au plus.

Pourquoi, et sur quelle base

  • Sauvegarder les données de la famille et les synchroniser entre ses appareils : c'est le service que le parent demande en créant le compte (exécution du service).
  • Protéger les comptes (codes à usage unique, limites d'essais) : intérêt légitime à la sécurité du service.

Les données des enfants ne sont traitées que dans le compte créé par leur parent, qui décide de les y mettre et peut tout effacer à tout moment.

Combien de temps

  • Les données du compte famille : tant que le compte existe. À la suppression, elles sont effacées immédiatement du serveur, et des copies de sauvegarde sous 30 jours au plus.
  • Un appareil jamais accepté par le parent, ou retiré : son identifiant anonyme est effacé au bout de 7 jours.
  • Les adresses IP des essais de code : un jour. Le journal des connexions : 30 jours. Les journaux techniques de l'hébergeur : 7 jours au plus.

Vos droits

Vous pouvez à tout moment accéder à vos données, les rectifier, les effacer, les récupérer dans un format réutilisable, vous opposer à leur traitement ou en demander la limitation.

  • Télécharger toutes les données de la famille : espace parent de l'une des apps, « Télécharger les données de la famille ».
  • Supprimer le compte et toutes les données de la famille : espace parent de l'une des apps, ou sans app sur compte.petitphare.fr.
  • Pour toute autre demande : contact@petitphare.fr.

Si vous estimez que vos droits ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL (cnil.fr).

Sécurité

Les échanges avec le serveur sont chiffrés (HTTPS). Le serveur ne laisse chaque appareil voir que l'enfant auquel il est rattaché, et chaque famille ne voit qu'elle-même. Les codes de connexion et d'appairage ne servent qu'une fois et expirent en 15 minutes au plus. Supprimer le compte, télécharger les données ou retirer un appareil demande un code e-mail récent.

Changements

Si cette politique change, la date en haut de la page change aussi. Un changement important sera annoncé dans les apps.
